## 🎮 Giới Thiệu (Overview)

Portfolio được thiết kế độc đáo với góc nhìn (POV) của **Lux Trợ Thủ (Support)** đảo đường (roaming), kiểm soát tầm nhìn và gánh đội (carry team) trên khắp bản đồ **Summoner's Rift** ở cánh team Xanh.

Khi Lux di chuyển đến từng vị trí trên bản đồ, nội dung CV tương ứng sẽ hiển thị:
- 🏰 **Bệ Đá Cổ (Fountain):** Hồ Sơ Triệu Hồi Sư (Thông tin cá nhân, MSSV, Liên hệ, Triết lý gánh đội)
- 🏹 **Đường Dưới (Bot Lane):** Học Vấn & Laning Phase (Đại Học Ngoại Thương FTU - Kinh Doanh Quốc Tế & Logistics LSCM)
- 🌿 **Khu Vực Rừng (Jungle):** Kỹ Năng & Tầm Nhìn (Research thông tin, Giao tiếp, Viết LSCM, Thiết kế Canva, Tin học VP)
- ⚔️ **Đường Giữa (Mid Lane):** Kinh Nghiệm Thực Chiến (Lớp Trưởng & Leader nhóm điểm A, Chuyên viên Sales Smile Media)
- 👑 **Đường Trên (Top Lane):** Đỉnh Cao Chiến Tích (Giải 3 Cuộc thi Khởi nghiệp I-BUDDY IBCONNECT)

## ✨ Tính Năng Nổi Bật

- 🗺️ **Bản đồ chiến thuật tương tác:** Biểu tượng lane LMHT chuẩn xác, Lux di chuyển theo lộ trình với thanh máu, thanh năng lượng và ping *"On My Way"*.
- ⚡ **Chế độ Tự Động Đảo Đường (Auto Roam):** Tuần tra 1 vòng từ Bệ Đá Cổ ➔ Bot ➔ Rừng ➔ Mid ➔ Top ➔ về căn cứ.
- 💥 **Tương tác Chiêu Cuối Lux [R] — Cầu Vồng Tối Thượng (Final Spark):** Bấm phím **R** hoặc click chiêu để ngắm và xả tia laser cực đại xuyên bản đồ, kèm hiệu ứng rung màn hình, âm thanh uy lực và bảng thông báo **PENTAKILL**!
- 🔊 **Âm thanh Web Audio API:** Tổng hợp âm thanh chuông ping, nạp năng lượng, laser blast và nhạc hiệu Pentakill ngay trên trình duyệt mà không cần tải file ngoài.
- 📱 **Tương thích mọi thiết bị:** Giao diện Hextech Runeterra sang trọng, hỗ trợ xem trên cả máy tính lẫn điện thoại.

## 🚀 Cách Chạy Dự Án Cục Bộ

1. Clone repository về máy:
   ```bash
   git clone https://github.com/CedricNguyen21/lol-lux-portfolio.git
   cd lol-lux-portfolio
   ```
2. Mở trực tiếp file `index.html` hoặc `portfolio-bundle.html` trên trình duyệt:
   ```bash
   # Hoặc mở server cục bộ
   python3 -m http.server 8080
   ```
3. Truy cập: `http://localhost:8080`
